An AI software factory for any project

Buildline installs a spec-driven pipeline that coding agents follow from idea to merged PR, with real quality gates, independent verification, and a clear place for developers, designers and product managers.

Why

Agents can build the feature. They need a factory around them.

Most repos give coding agents a prompt and hope. Buildline gives them the three things that turn a good demo into work you can merge.

02"It works on my end."

A way to check the work

Your own lint, types, tests and build as gates, plus a verifier agent that never saw the code being written.

03Every chat starts from zero.

Memory between sessions

Specs, task lists with passes flags and progress logs on disk, so any session picks up exactly where the last one stopped.

Models per station

Your models, for each job

Fable to plan, Opus to build, Codex to review, or anything else your tools support. Buildline reads what's available from Claude Code and the Anthropic API, so tomorrow's models show up without an update.

  • Pick by phase or per station, or type any model name or id.
  • Aliases keep up: fable always means the newest Fable. Full ids pin a model.
  • Codex and Gemini stations are handed off automatically.

How models work

$ npx buildline models set planning fable
$ npx buildline models set building claude-opus-5-5
$ npx buildline models set review codex

$ npx buildline models check
  ✔ fable            → claude-fable-5-1
  ✔ claude-opus-5-5  → claude-opus-5-5
  ✔ codex            → installed
In your terminal

Watch the line move

npx buildline watch draws every feature on its own track through the stations and updates live. A comet means an agent is up; a blinking dot means a person is.

Guardrails

Rules that hold, not rules that hope

Instructions in prose are advice. These are enforced by hooks, separate contexts and files on disk.

  • Acceptance lock. A hook blocks edits to a spec's acceptance scenarios while the feature is being built, verified or reviewed.
  • Independent verification. The verifier starts in a clean context with only the spec, so the builder never grades its own work.
  • Evidence before done. A task flips to "passes": true only after its check and the gates have been run and observed.
  • Humans merge. Always, at every autonomy level.
  • Your files stay yours. Marked blocks, hash-tracked files, edits kept on update, and a clean remove.
Autonomy

Dial it up as trust is earned

Start guided. Raise the level when your gates and acceptance scenarios have proven themselves. At level 3, buildline run drives Claude Code's /goal until the feature is ready.

L1

Assist

A human approves every station. The agent never moves on alone.

L2

Guided

Humans approve spec and plan. Agents build, verify and review.

L3

Autopilot

Humans approve the spec. Plan through review runs unattended.

L4

Dark factory

Spec to ready PR with no checkpoints. A human still merges.
